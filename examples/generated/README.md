# Generated Cause Lowercase Alphabet

[`cause-lowercase.zip`](cause-lowercase.zip) contains 26 ready-to-print STL
stamp heads (`a` through `z`) plus the generator `manifest.json`.

This is the approved lowercase example set generated with:

```bash
./scripts/generate.py alphabet \
  --google-font Cause \
  --font-style Regular \
  --case lowercase \
  --height 10 \
  --scale 0.75 \
  -o build/cause-lowercase
```

Key parameters:

| Parameter | Value |
|---|---:|
| Font | Cause Regular |
| Characters | `a`–`z` |
| Nominal height | 10 mm |
| Scale | 0.75 |
| Effective height | 7.5 mm |
| Relief height | 1.2 mm |
| Flare height | 2.4 mm |
| Flare amount | 1.2 mm |
| Thin support height | 0 mm |
| Body size | 20 × 20 mm |
| Overhang limit | 45° |

The ZIP archive contains 26 manifold STL files and has been tested with
`unzip -t`.
